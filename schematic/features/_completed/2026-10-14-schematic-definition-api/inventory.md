## Default audit and allow-list

REST value types RestApi, Endpoint, Schema, ParamDef, QueryParamType, ParamStyle, and RestMethod have no Default. Keep EndpointParams (empty collections mean no parameters), AuthStrategy (explicit None is meaningful internally, but API builders still require auth choice), AuthPolicy (empty explicit methods is meaningful data), CrossOrigin (SameOrigin), EnvMapping (no environment fallback), PkceRequirement (Optional), and OAuth2ClientAuthMethod (None). This is an audit proposal for Phase 3, not permission for API/Endpoint/builders to acquire Default.

Other public Defaults in schematic-define are outside required-fact REST construction: Headers and SensitiveString (empty header accumulator/value); WebSocketEndpoint, ConnectionLifecycle, WebSocketRuntimeHints, WebSocketEndpointHints (existing WebSocket authoring behavior); ExportFormat/ExportOptions and OpenApiImportOptions (tool options); SchematicDocExtension and SchematicSchemaExtension (empty extension data). Preserve rather than refactor these in this migration. SchemaRegistry Default is an empty ordered collection in schematic-definitions. Generated request/body/type Defaults are outside this audit and stay intact.
