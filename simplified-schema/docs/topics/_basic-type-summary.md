| Type | Description |
| ---- | ----------- | 
| string | any string value including strings like "3" or "true" which might be coerced into a different type |
| number | any numeric value; does not strictly include numeric strings like "3", "100", etc. but these values will be _coerced_ into a property that is typed as **number** |
| boolean | a boolean true/false value |
| null | a `null` value; which is the same as _undefined_ |
