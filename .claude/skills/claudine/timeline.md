# Claudine Change Timeline

Condensed history of significant Claudine features and refactors, newest first. Each entry names the feature/fix slug and the durable takeaway; deep references live in the linked docs. For current behavior always trust [architecture.md](architecture.md), [cli-reference.md](cli-reference.md), and the repo `docs/topics/*` — this file is historical context, not a spec.

## 2026-05

- **2026-05-12 — `improved-error-handling`**: Compose-loop errors split out of the overloaded `LoopInvalid`. New `LoopIterationFailed { iteration, prompt_path, exit_code, reason, exit_reason }` and `LoopRateLimited { ... reset_at, message }`; `reason`/`exit_reason` come from the iteration's `session_end` JSONL row. Loop became rate-limit-aware via `loop.on_rate_limit: pause|abort|continue` (default `pause`), `--on-rate-limit`, and exit code `75` (`EX_TEMPFAIL`). `LoopInvalid` now means frontmatter parse failure only.
- **2026-05-12 — `opencode-stderr-returns`**: OpenCode **Dual-Source Contract**. Stdout NDJSON is "DONE-only" (no tool starts, no `task_started`), so the wrapper opts into structured stderr via `--print-logs --log-level INFO` and `OpenCodeLogBridge` promotes selected log records to first-class `SemanticEvent`s. Full mapping in [opencode-event-sources.md](opencode-event-sources.md).
- **2026-05-11 — `2026-05-10-prompt-reporting` (Phases 1-3)**: New `prompt_reporting` module — system/user prompt reporting, frontmatter verbosity parsing, precedence, token estimation, truncation, and markdown formatting with the system-prompt reporter.
- **2026-05-10 — `opencode-timeout-regression`**: Silence rule hardened after commit-style OpenCode flows were misread as hangs. Three layers: a provider-agnostic raw-byte heartbeat (`last_byte_at`), a per-step `provider_status` grace (silence suppressed `step_start`→`step_finish`), and synthesized `SubagentStart`/`SubagentStop` from completed `task` tools. Guard is OpenCode-only; zero-byte hangs still trip `step_timeout`.
- **2026-05-06 — `2026-05-06-looping`**: Per-prompt looping. `loop` frontmatter parsed in `composition/loop_config.rs`; action engine (`increment`/`decrement`/`set`/`append`/`prepend`/`merge` with all-or-nothing `ActionStaging`); Darkmatter condition evaluation against `env.*` and ambient vars (`iteration`, `is_first`, `is_last`, `last_output`, `last_exit_code`); `max_iterations` cap and `CLAUDINE_MAX_ITERATIONS`.
- **2026-05-06 — `2026-05-02-flattened-bridge` (Phases 4-5)**: Non-interactive terminal rendering hardened. Plain/`NO_COLOR` paths start from `Terminal::new_optimistic(width)` and clamp `is_tty=false` to avoid OSC 11 color probes; wrapper startup delays terminal construction until interactivity is known. Removed the legacy JSON-serialize-and-flatten expression path.
- **2026-05-03 — `2026-05-02-opencode-stability` (Phase 4)**: Unified timeout watchdog. Exactly two rules — `timeout` (wall-clock, opt-in, no default) and `step_timeout` (stream-silence, default `30m`) — with consistent vocabulary across CLI flags, frontmatter, and env vars (`CLAUDINE_TIMEOUT`, `CLAUDINE_STEP_TIMEOUT`, `CLAUDINE_KILL_GRACE`, `CLAUDINE_WATCHDOG_INTERVAL`). Replaced the old `CLAUDINE_SUBAGENT_*` / `CLAUDINE_STREAM_IDLE_*` knobs. Canonical reference: [Timeouts](../../../claudine/docs/topics/timeouts.md).

## 2026-04

- **2026-04-29 — `2026-04-29-leverage-dm-parser`** (hardened 2026-05-06): Dispatch expression bridge unified. `EventMetaExpressionLookup` is the single source of truth for non-`ctx` path resolution across templates, matchers, and harness validation; hook `when` clauses add `ctx.*` via the composite `EventMetaConditionLookup`. Templates gained fallbacks (`||`), ternaries, comparisons, and helpers (`length(...)`); matchers became `RuntimeMatcher::{Regex, Expression}`.
- **2026-04-26 — `2026-04-26-just-flow` (Phase 1)**: Package-local compose prompts added under `claudine/prompts/` (design, plan, phase implementation, commit, review) for the planned `just flow` lifecycle — distinct from repo-level `prompts/`.
- **2026-04-25 — `2026-04-25-agent-selection` (Phases 3-6)**: Composition provider/model resolution redesign. Removed the `SingleInstalled` auto-selection shortcut; TTY shows an interactive picker, non-TTY follows a strict resolution chain. Added the model catalog service (`~/.claudine/cache/models/<provider>.json`), wired the executor and sequence orchestrator through `ResolvedExecutionTarget`, and replaced `inquire` UI with `tui-chrome`.
- **2026-04-18 — research refresh**: Claude `RateLimitStatus` naming drifted to `allowed` / `allowed_warning` / `rejected`. The Claude stream formatter still special-cases older `approaching_limit` / `limited` names — treat both schemes as version-sensitive.
- **2026-04-17 — `2026-04-17-cli-pre-processing`**: `argv::normalize` pre-parses argv before clap with four fixed-order syntactic rules (provider booleans → `--provider`, provider canonicalization, `--help` hoisting, `--` separator insertion). Reference: [CLI Pre-Parsing](../../../claudine/docs/topics/cli-pre-parsing.md).
- **2026-04-16 — `2026-04-16-more-is-more`**: Non-interactive stderr strengthened. Tool calls render as `Name(summary)` / `←Name(slot)`; shell tools prepend the shell name; `flush_if_idle` flushes dangling paragraphs; OpenCode gained a typed `Reasoning` variant; `SemanticEvent::Error` gained a typed `kind: SemanticErrorKind`.
- **2026-04-16 — `2026-04-16-consistent-rendering`**: `compose` and `inline-compose` unified onto one non-harness `execute_without_harness` function plus a shared structured-stream helper and summary emitter (`defer_section_separator` selects immediate vs. deferred emission).
- **2026-04-14 — `2026-04-14-response-refinement`**: Live stderr surface gained the 9-section non-interactive model with strict spacing, the canonical `ToolCallDisplay` contract (`🔧 →` / `🔧 ←`, no raw JSON), the Gemini markdown-list fix, and OpenCode `--yolo` → `--dangerously-skip-permissions`.
- **2026-04-14 — `2026-04-14-more-meta-response` (Plan 1)**: `claudine handle` enforces a 5-second execution deadline (`CLAUDINE_HANDLE_DEADLINE_SECONDS`, exit 124) plus 3-second bash/messenger timeouts inside hook handlers, with phase-level tracing spans.
- **2026-04-11 — stream refactor**: Stream parsing moved onto strongly typed serde protocol models in `stream/protocol/` (one module per provider). All fields optional via `#[serde(default)]`, no `deny_unknown_fields`, unknown event types skip silently, field aliases resolved by helper methods, and `feed_line` uses two-pass dispatch (Value first, then typed enum).
- **2026-04-06 — Protect refactor**: `ProtectService` became a standalone regex-backed deny catalog — strict `Allow`/`Block`, no posture or severity model, no `PolicyEngine` dependency, per-group toggles plus command-only `custom_patterns`. Promoted to a top-level `protect` module on 2026-05-04. Reference: [Protect Service](../../../claudine/docs/topics/protect-service.md).
