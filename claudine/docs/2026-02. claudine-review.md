# Claudine package code review (2026-02)

## Findings

1. **Swapped recipe descriptions for `oc` and `cc` in `claudine/justfile`**
   - `oc` is documented as opening Claude Code, but it runs `opencode`.
   - `cc` is documented as opening Opencode, but it runs `claude --dangerously-skip-permissions`.
   - This is user-facing (`just --list`) and can lead to launching the wrong CLI, including unexpectedly running Claude in yolo mode.

## Overall verdict

Patch needs a small follow-up fix to align the recipe descriptions with the commands they execute.
