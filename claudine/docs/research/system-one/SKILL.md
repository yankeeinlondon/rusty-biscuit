In September 2026, **Jev** was announced by a company called **Typesafe AI** and suddenly everyone was talking about a new class of model called "system one" models. This name comes from the popular book "Thinking slow, Thinking fast" which coined the terms System One (subconscious mind) and System Two (conscious mind).

- [Jev](./jev.md) get more details on Jev, it's API, what it's good at, what it's not good at, etc.
- [Kev](./kev.md) get details on an open source variant of the system-one model
- [Laya](./laya.md) is another popular open source system-one alternative to Jev
- [CLM-8b](./clm-8b.md) another model which talks about the revival of contrastive modeling but clearly is aiming at the same problem space as Jev

If you want an overview of other alternatives and a more academic look at these new architectures, then read [About System One Models](./about.md).
