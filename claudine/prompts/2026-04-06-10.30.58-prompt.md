The Claudine `sequence` is emitting status updates like:

```txt
step 3/5 succeeded (via Codex)
[4/5] Kimi Code CLI
```

These are poorly formatted. We should be using the `Status` struct to wrap these commands.
Furthermore, we should the `Prose` struct to provide nicer looking messages for the terminal.

For example, I'd expect these two lines to look more like:

```rs
// as Success state
let closure = Struct::from_prose("step <b><yellow>{#}</yellow>/{#}</b> succeeded (<dim><i>via {provider}</i></dim>)");
// as Info state
let starting = Struct::from_prose("[<yellow>{#}/{#}] <i>starting</i> <b>{name}</b>")
```

In addition if there is a failure it too should use the `Status` struct (in error state).
