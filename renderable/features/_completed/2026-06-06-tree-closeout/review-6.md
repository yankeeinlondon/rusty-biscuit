# Review 6

## Findings

### High: The new Level 2 test does not verify OSC8 capability parity

`level2_matched_layout_policy_matches_no_policy_capabilities_in_real_terminal`
renders both pages in the test process before opening WezTerm, writes the
already-generated bytes to files, and only has the pane `cat` those files
(`darkmatter/lib/tests/level2_render_tree_terminal.rs:1438-1456`,
`:1571-1580`). Terminal capability detection therefore happens outside the real
terminal. The test cannot establish what `DarkmatterPage::render` selects when
actually invoked under WezTerm's environment.

The hyperlink assertion is also non-discriminating. It reduces each capture to
whether visible pane text contains `example.com` (`:1608-1619`). That proves
only that the two pre-rendered files chose the same fallback representation; it
does not inspect OSC8 metadata, clickability, or the raw bytes selected inside
the terminal. A regression that changes both renders identically, or a capture
backend that discards hyperlink metadata, still passes.

The source fix itself is credible and its Level 1 capability-signature test
passes, but review 5 explicitly required real-terminal parity for color and
hyperlink behavior. Run the renderer process inside the WezTerm pane, then use a
capture/API that exposes hyperlink metadata or emit the produced bytes through
an IPC side channel for an exact OSC8 comparison. Until that requirement has
valid Level 2 evidence, acceptance criterion 8 is not met.

### Medium: The recorded terminal benchmark improvement is arithmetically wrong

`performance-record.md` says the terminal median fell from approximately
412 µs to 374 µs, “a ~17% reduction”
(`renderable/features/2026-06-06-tree-closeout/performance-record.md:79-83`).
That reduction is about 9.2%. The browser change from 197 µs to 123 µs is about
37.6%, but no percentage is stated for it.

Correct the terminal percentage or omit percentages from these deliberately
short trend runs. The current record is inaccurate evidence for acceptance
criterion 7 even though the underlying medians may be valid.
