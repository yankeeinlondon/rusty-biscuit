# Collective Wisdom

A library and CLI that tries to capture an individual's core digital footprint including:

- My People
    - who are the people in the person's contacts list(s)
    - who is emailed the most? all time? lately?
    - how would each person be categorized? friend? colleague? etc.
    - what meetings have been held with each person (from calendar)
- Watching
    - Musicians
    - Politicians
    - Sports stars
    - Social influencers
- Topics
    - For each thing i've expressed an interest in:
        - when I have talked about this topic on various platforms?
        - what RSS feeds have been associated with this topic?
        - what "research topics" map to this interest topic?
        - articles which _appear_ to be related to this topic
        - articles I've _favorited_ and agree belong to the topic
- Locales
    - Where is Home?
    - Where is Work?
    - What other "important places" do I care about?
