directory.

## Manifest (`claudine-cli-migration.json`)

Generated by `consolidation.py plan --package claudine-cli --listings
selfproof/capture-a`. It has not been hand-edited, apart from two recorded
fields:

- **`dispositions`** has one entry.
  `level2/level2_provider_overlay_capture.rs` trips the `current_exe_list`
  identity detector, a false positive. `current_exe()` is inside
  `RECORDER_SOURCE`, which is a separate program's source text, and `--list` is
  `gpg --list-keys`.

  (acceptance 12).

## Measurements and seam decision

`measurements.md` §"After series" and §"Seam decision". Alternating pair,
kache off: clean build 125.4 → 99.9 s. Test executables 2.80 → 0.23 GB. Peak
compiler RSS 3.74 → 3.76 GB. Median edit-to-one-test 2.41 → 2.71 s (+0.30 s,
+12%). **Decision: one binary per contract.** Neither guardrail part is met.

## Defects and oddities found (not fixed here; separate-defect candidates)

1. **Linux-only, pre-existing:** `sequence_groups::{parallel_body_lines_carry_their_own_tasks_bar_color,
   parallel_group_members_are_attributed_across_both_channels,
   serial_and_parallel_group_frames_share_one_left_edge}` fail on
   `build-linux` on the **unmigrated** base (3 of 3 runs, and 10 of 10 for the
   first), identically after the move. They pass on macOS. The parallel
   group's `│ > <task>` header lines are missing or out of order in the
   rendered output.
2. **Orphan snapshots, pre-existing:** `claudine/cli/claudine/cli/tests/snapshots/wrap_commands__*.snap`
   (2) belong to a test file deleted long ago. `wrap_basics__wrapper_help_includes_expected_flags.snap`
   is read by no test (its test asserts on text now). All were preserved
   byte-for-byte.
3. **Stale doc, pre-existing:** `claudine/docs/topics/testing.md:20` names
   `--test level2_pty_tests`, a target that did not exist before this change
   either.
4. **Measurement protocol:** the Phase 1 before series ran with kache on
   (`measurements.md` §Correction).
