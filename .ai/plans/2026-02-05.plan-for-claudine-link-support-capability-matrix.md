## Implementation Summary

### Files Created

- `claudine/lib/src/linking/capabilities.rs` - New module with:
  - `LinkableResource` enum (Skill, Command, Agent, Script)
  - `ResourceFormat` enum (Markdown, Toml, Yaml, Mcp, BuiltinOnly, Executable)
  - `SupportLevel` enum (Full, CustomFormat, Limited, None)
  - `ResourceSupport` struct with format, paths, notes
  - `SkillFrontmatter` struct for frontmatter field tracking
  - `ProviderCapabilities` struct aggregating all resource types
  - `capabilities_for(provider)` and `all_capabilities()` lookup functions
  - `ALL_PROVIDERS` constant for iteration
  - 17 unit tests covering all providers and capabilities

### Files Modified

- `claudine/lib/src/linking/mod.rs` - Added exports for capabilities module
- `claudine/cli/src/commands/link.rs` - Added:
  - `--support` flag for capability matrix
  - Provider argument for detailed view
  - Fuzzy provider matching
  - Table rendering with biscuit_terminal
  - Cross-provider discovery section
  - Skill frontmatter fields section

### New Commands

```bash
# Show capability matrix for all providers
claudine link --support

# Show detailed capabilities for a specific provider
claudine link claude
claudine link --support opencode
claudine link goo  # fuzzy matching to "Goose"
```
