## Lessons Learned

- [TECHNICAL]: Gitea's `/git/refs/{ref}` endpoint returns an array, unlike GitHub's single object
- [TECHNICAL]: Gitea uses `limit` parameter (not `per_page`) with default 50
- [TECHNICAL]: Gitea issues endpoint supports `type=issues` filter to exclude PRs
- [CODE-GEN]: Path parameters using Rust keywords (like `{ref}`) cause generation failure - use alternatives like `{git_ref}`
- [AUTH]: ApiKey auth strategy doesn't support automatic prefix injection - users must set `GITEA_TOKEN=token <pat>` with prefix
