- [schematic]: GetProject endpoint missing in GitLab - mitigated via ListRepositoryTree
- [schematic]: PaginatedResponse requires Default derive on inner types
- [wiremock]: Environment variable set_var is unsafe in Rust 2024 edition
- [clippy]: Nested if with if let should use let-chains syntax
- [clippy]: map_or(false, ...) should be is_some_and(...)
