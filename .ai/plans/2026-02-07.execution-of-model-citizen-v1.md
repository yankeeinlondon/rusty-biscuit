## Lessons Learned

- [RUST 2024]: `std::env::set_var` and `std::env::remove_var` are now unsafe - tests must use unsafe blocks with proper safety comments
- [SKILL: schematic]: HuggingFace client exists but for model-citizen we implemented a simpler direct reqwest-based client for GGUF-specific operations
- [PATTERN: async-trait]: Still required for `dyn Trait` with async methods even in Rust 2024
- [CRATE: urlencoding]: Required for encoding search queries in HuggingFace API URLs
