Plan: Modularize visual diff

Goals
- Decouple visual diff from Markdown and markdown::delta.
- Provide a small, stable API for string/file visual diffs with ANSI output.
- Preserve existing behavior (layout threshold, coloring, context logic).

Scope
- Move visual diff logic into a standalone module.
- Add minimal wrappers for string and file usage.
- Re-export to keep user-facing paths convenient.

Out of scope
- Semantic MarkdownDelta changes.
- Rendering/style tweaks.
- New dependencies.

Design decisions
- New module path: darkmatter/lib/src/diff/visual/* (standalone from markdown).
- Keep existing algorithm types (DiffLine, InlineSpan) public.
- Add a small mode enum and optional output struct for clarity.
- Provide file helpers but keep I/O thin and optional.

Proposed public API
- pub mod diff::visual
  - pub struct VisualDiffOptions { terminal_width: u16, show_line_numbers: bool, context_lines: usize }
  - pub enum VisualDiffMode { Auto, SideBySide, Unified }
  - pub struct VisualDiffInput<'a> { original: &'a str, updated: &'a str, label_original: &'a str, label_updated: &'a str }
  - pub struct VisualDiffOutput { rendered: String, mode: VisualDiffMode, stats: VisualDiffStats }
  - pub struct VisualDiffStats { added: usize, removed: usize, modified: usize, unchanged: usize } (optional)
  - pub fn compute_visual_diff(original: &str, updated: &str) -> VisualDiff
  - pub fn render_visual_diff(input: VisualDiffInput<'_>, options: &VisualDiffOptions) -> VisualDiffOutput
  - pub fn render_visual_diff_str(original: &str, updated: &str, options: &VisualDiffOptions) -> String
  - pub fn render_visual_diff_files(path_a: &Path, path_b: &Path, options: &VisualDiffOptions) -> io::Result<String>
  - pub fn default_labels(path_a: &Path, path_b: &Path) -> (String, String) (optional)
