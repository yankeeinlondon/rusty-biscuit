## Lessons Learned

- [PATTERN: Headers API]: Used `Vec<String>` instead of `Vec<&'static str>` for EnvList to avoid lifetime mismatch with RestApi.env_auth
- [SECURITY: SensitiveString]: Omitted PartialEq/Eq to prevent timing attacks on credential comparison
- [SKILL: schematic]: Testing gap - schematic tests verify syntax only, not runtime behavior; wiremock integration tests essential
- [CLIPPY: collapsible_if]: Modern Rust (1.92+) prefers `if condition && let pattern` syntax over nested ifs
