# Native-First Audio Playback with Host Player Fallback

## Context

Playa currently has two separate playback paths:

1. **Host player** (general audio): Spawns 1 of 13 external programs (mpv, ffplay, sox, afplay, etc.) as subprocesses. Handles all formats but requires external software to be installed.
2. **Native SFX** (sound effects only): Uses rodio in-process for WAV/MP3/OGG with OS-specific audio routing (macOS system sound device, Windows WASAPI SoundEffects category, Linux PulseAudio media.role=event).

This plan generalizes native playback to ALL audio — trying rodio/symphonia first and falling back to host players only when the native decoder can't handle the format or fails. This eliminates the dependency on external programs for common audio formats, gives us programmatic control (volume, speed), and eliminates the current limitation where ducking bypasses native playback.

## Design Decisions

| Decision | Choice |
|----------|--------|
| URL sources | Always route to host players (no download-then-play) |
| OS audio routing | Extract from sfx_player into shared module for reuse |
| Ducking + native | Integrate — DuckGuard set up before native/host decision |
| Decoder backend | Standardize on symphonia for all native decoding |

## Native Format Coverage

rodio 0.22.1 exposes comprehensive symphonia features. With the targeted set enabled:

| Format | Container | Codec | Native | symphonia feature |
|--------|-----------|-------|:------:|-------------------|
| WAV | RIFF | PCM | yes | symphonia-wav, symphonia-pcm |
| AIFF | IFF | PCM | yes | symphonia-aiff |
| MP3 | — | MP3 | yes | symphonia-mp3 |
| OGG | OGG | Vorbis | yes | symphonia-ogg, symphonia-vorbis |
| FLAC | — | FLAC | yes | symphonia-flac |
| M4A | ISO MP4 | AAC | yes | symphonia-isomp4, symphonia-aac |
| M4A | ISO MP4 | ALAC | yes | symphonia-isomp4, symphonia-alac |
| WebM | MKV | Vorbis | yes | symphonia-mkv, symphonia-vorbis |
| OGG | OGG | Opus | **no** | no symphonia opus codec (0.5.x) |
| WebM | MKV | Opus | **no** | no symphonia opus codec |

Only **Opus** remains host-player-only. All other formats playa knows about get native coverage.

## Phase 2: Create native_player module

**New file**: `playa/lib/src/native_player.rs`

Feature-gated on `native-playback`.

### Error type

```rust
#[derive(Debug, Error)]
pub enum NativePlaybackError {
    #[error("format not supported for native playback: {0:?}")]
    UnsupportedFormat(AudioFormat),

    #[error("native playback does not support URL sources")]
    UrlNotSupported,

    #[error("failed to open audio stream: {0}")]
    Stream(#[from] rodio::DeviceSinkError),

    #[error("failed to decode audio: {0}")]
    Decode(#[from] rodio::decoder::DecoderError),

    #[error("failed to play audio: {0}")]
    Play(#[from] rodio::PlayError),

    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
}
```

### Format support check

```rust
pub fn can_decode_natively(format: AudioFormat) -> bool {
    match format.file_format {
        Wav | Aiff | Mp3 | Flac | M4a | Webm => match format.codec {
            None => true,           // unknown codec in supported container — try it
            Some(Opus) => false,    // no symphonia opus decoder
            Some(_) => true,
        },
        Ogg => match format.codec {
            Some(Opus) => false,
            _ => true,
        },
    }
}
```

### Core playback function

```rust
pub fn play_native(
    audio: &AudioData,
    format: AudioFormat,
    options: &PlaybackOptions,
) -> Result<(), NativePlaybackError> {
    if !can_decode_natively(format) {
        return Err(NativePlaybackError::UnsupportedFormat(format));
    }

    match audio {
        AudioData::Url(_) => Err(NativePlaybackError::UrlNotSupported),
        AudioData::Bytes(bytes) => play_from_bytes(bytes, options),
        AudioData::FilePath(path) => play_from_file(path, options),
    }
}
```

- `play_from_bytes()`: `Decoder::new(Cursor::new(bytes.to_vec()))` → open default stream → set volume/speed → `sleep_until_end()`
- `play_from_file()`: `Decoder::new(BufReader::new(File::open(path)?))` → same flow
- Both use `DeviceSinkBuilder::open_default_sink()` (general audio goes to default output device, not SFX-specific routing)

### Register in lib.rs

**File**: `playa/lib/src/lib.rs`

### Unit tests

- `can_decode_natively` returns true for WAV/MP3/OGG-Vorbis/FLAC/M4A-AAC/AIFF/WebM-Vorbis
- `can_decode_natively` returns false for OGG-Opus, WebM-Opus

### Modify `play_async()` — ducking integration

Key change: DuckGuard is set up **before** the native/host decision so both paths benefit.

```rust
#[cfg(feature = "audio-ducking")]
pub async fn play_async(self) -> Result<(), PlaybackError> {
    let format = self.audio.format();

    // Set up ducking BEFORE playback (covers both native and host paths)
    let guard = if let Some(config) = self.duck_config {
        let backend = create_backend();
        match DuckGuard::new(backend, config).await {
            Ok(guard) => Some(guard),
            Err(e) => {
                eprintln!("Warning: audio ducking failed to initialize: {}", e);
                None
            }
        }
    } else { None };

    // Try native playback first
    #[cfg(feature = "native-playback")]
    if !self.force_host && !matches!(self.audio.source_kind(), AudioSourceKind::Url) {
        if let Ok(()) = crate::native_player::play_native(
            self.audio.data_ref(), format, &self.options,
        ) {
            if self.show_meta { self.print_native_meta(format); }
            if let Some(guard) = guard { guard.restore().await; }
            return Ok(());
        }
    }

    // Host player fallback
    let player = self.select_player(format)?;
    if self.show_meta { self.print_meta(player, format); }
    let result = playa_with_player_and_options(player, self.audio.into_data(), self.options);
    if let Some(guard) = guard { guard.restore().await; }
    result
}
```

### Remove SFX ducking exclusion

The current code in `play_effect()` (async variant, ~line 399) skips native SFX when ducking is active:

```rust
// CURRENT (remove this guard):
#[cfg(feature = "sfx-native")]
if !opts.has_ducking() {
    if playa::sfx_player::play_sfx(effect.bytes(), &opts.to_lib_options()).is_ok() {
        return;
    }
}
```

Replace with ducking-aware SFX playback that preserves OS audio routing:

```rust
// NEW: SFX native playback works with ducking
#[cfg(feature = "sfx-native")]
if !opts.force_host {
    // Set up ducking first if configured
    #[cfg(feature = "audio-ducking")]
    let guard = if opts.has_ducking() {
        let backend = create_backend();
        DuckGuard::new(backend, DuckConfig::new(opts.duck_ramp_ms, opts.duck_floor)
            .unwrap_or_default()).await.ok()
    } else { None };

    if playa::sfx_player::play_sfx(effect.bytes(), &opts.to_lib_options()).is_ok() {
        #[cfg(feature = "audio-ducking")]
        if let Some(guard) = guard { guard.restore().await; }
        return;
    }
    // Fall through to Playa builder path (which also tries native, then host)
}
```

Apply the same change to `play_effect_sync()` (non-ducking variant, ~line 452) — just remove the ducking guard since sync doesn't have ducking.
