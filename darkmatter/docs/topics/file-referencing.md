# Local File Referencing

Whenever Darkmatter provides for a local file reference the _kinds_ of file references we allow will be derived from the capabilities that the [**biscuit-file**](@biscuit-file/README.md) package provides us:

- **Relative** paths
    - **Explicit Relative:**
        - an _explicitly_ relative path starts with the `.` or `..` symbol indicating the current working directory or the parent of the current working directory
        - the current working directory in explicitly relative paths is always the document being composed
        - 
    - **Implicit Relative:**
- **Absolute** paths
- **Multi-homed** paths
