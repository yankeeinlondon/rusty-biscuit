# OSC 1337 (iTerm2 proprietary extensions)

OSC 1337 is a vendor extension namespace maintained by iTerm2, not an ECMA-48 or xterm standard. Its command grammar is generally `ESC ] 1337 ; <command and parameters> ST`; `ST` is `ESC \\`, and iTerm2 also accepts BEL (`0x07`) as the terminator. Payloads may be plain text, key/value parameters, or base64-encoded data. Unknown OSC commands are normally ignored by unrelated terminals, but there is no universal capability negotiation for this namespace. A program should select a feature from a known terminal identity/configuration or offer a fallback; do not infer support merely because output did not visibly fail.

The namespace began as an iTerm2-specific replacement for an older OSC 50 profile command that conflicted with xterm usage. iTerm2's publicly documented image protocol has been present since at least 2015 (animated GIF support was added in 2.9.20150512); the namespace has accumulated features over time, including newer multipart image transfer (iTerm2 3.5) and blocks/buttons (3.6.9). The live iTerm2 documentation is the closest thing to a normative reference, but it is a moving vendor specification. Adoption is durable for the image subset because `imgcat` and compatible tools emit it; broader adoption is limited. Terminals more often implement the portable OSC 133 shell-marking protocol, OSC 7 for working directory, or their own graphics protocol. There is continuing feature work in iTerm2 and some compatibility implementations, but no cross-vendor standardization trend for the full namespace.

## How applications send it and test support

The application writes the escape sequence to the terminal's output stream. For images, `File=` carries optional metadata followed by `:` and base64 bytes; it may download a file without displaying it (`inline=0`) or place an image at the cursor (`inline=1`). The receiver decodes and renders/handles it. Multipart transfer uses `MultipartFile=`, one or more `FilePart=` chunks, and `FileEnd`; this avoids oversized OSC strings in tmux integration. Other commands update terminal-side metadata, session UI, clipboard, or shell-integration state.

There is no general, safe “does this terminal support OSC 1337?” query. `TERM`, `TERM_PROGRAM`, and similar environment variables are hints, not protocol negotiation, and multiplexers/SSH can intercept or discard sequences. `ReportCellSize` is a narrow active query: supported iTerm2 versions reply with an OSC 1337 `ReportCellSize=height;width[;scale]` response. Lack of a reply is inconclusive and querying does not establish support for other commands. In practice use an explicit allowlist based on tested terminal/version, provide a textual or alternate graphics fallback, and test through the actual multiplexer/remote path. A harmless image probe can verify rendering manually, but an automated test needs a known terminal harness and must account for terminals that consume control sequences without producing a reply.

## Command inventory and implementations

The names below are iTerm2's documented command families. “Other implementations” means documented or source-visible terminal support, not merely that an application passes escape bytes through. Blank means no implementation found in the terminal's published documentation/source; it is not proof that a downstream fork cannot add one.

| Command family                                    | Purpose / visible result                                                                                                                                                | Other terminals with known implementation                                                                                                  |
|---------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| `File=`, `MultipartFile=`, `FilePart=`, `FileEnd` | File transfer, downloads, and inline images. `inline=1` paints at the cursor; sizing accepts cells, pixels, percentages, or `auto`; aspect ratio is normally preserved. | WezTerm; Konsole (File image subset). Ghostty's documented compatibility is limited and should be verified by version; see app notes.      |
| `SetUserVar=`                                     | Stores a base64 value in iTerm2's per-session user-variable dictionary, usable in substitutions such as badges/status items.                                            | WezTerm supports the iTerm2 user-variable escape.                                                                                          |
| `CurrentDir=`                                     | Reports current directory to iTerm2 shell integration/session features.                                                                                                 | No distinct 1337 implementation identified; prefer OSC 7, which is more widely implemented.                                                |
| `RemoteHost=`                                     | Reports user and host for profile switching, history, and remote-file features.                                                                                         | No distinct 1337 implementation identified.                                                                                                |
| `SetMark`                                         | Adds a navigation point in scrollback. With shell integration, iTerm2 marks prompts; its gutter mark is a small triangle and command failures can be colored.           | No distinct 1337 `SetMark` implementation identified. OSC 133 prompt marks are a different protocol and are implemented by many terminals. |
| `SetBadgeFormat=`                                 | Sets a dynamic text badge in the upper-right of the iTerm2 session, with configurable font and color.                                                                   | None identified.                                                                                                                           |
| `SetProfile=` / `SetProfileProperty=`             | Switches profile or changes profile properties at runtime.                                                                                                              | None identified.                                                                                                                           |
| `CopyToClipboard=` / `EndCopy`                    | Captures intervening stream text into a named iTerm2 pasteboard.                                                                                                        | None identified. Prefer OSC 52 only where its security and support model is appropriate.                                                   |
| `AddAnnotation=` / `AddHiddenAnnotation=`         | Attaches a message to a span of scrollback; the visible form opens the annotation UI, hidden form does not.                                                             | None identified.                                                                                                                           |
| `HighlightCursorLine=`                            | Shows/hides iTerm2's cursor-line guide.                                                                                                                                 | None identified.                                                                                                                           |
| `RequestAttention=`                               | Requests dock attention; `fireworks` displays an effect at the cursor.                                                                                                  | None identified.                                                                                                                           |
| `SetBackgroundImageFile=`                         | Sets a background image from a base64-encoded path; iTerm2 requires user confirmation.                                                                                  | None identified.                                                                                                                           |
| `ReportCellSize`                                  | Replies with cell height, width, and optionally display scale; no visual output.                                                                                        | None identified.                                                                                                                           |
| `UnicodeVersion=`                                 | Selects/pushes/pops iTerm2's Unicode width-table version.                                                                                                               | None identified.                                                                                                                           |
| `ShellIntegrationVersion=`                        | Reports the shell-integration script version and shell name.                                                                                                            | No distinct 1337 implementation identified.                                                                                                |
| `ClearCapturedOutput`                             | Clears iTerm2's captured-output area.                                                                                                                                   | None identified.                                                                                                                           |
| `Block=` / `UpdateBlock=` / `Button=`             | Defines/collapses scrollback blocks and creates copy/custom action buttons (iTerm2 3.6.9+).                                                                             | None identified.                                                                                                                           |
| `Custom=`                                         | Registers a secret-gated custom control sequence with an iTerm2 script.                                                                                                 | None identified.                                                                                                                           |

The visible effects are deliberately terminal-specific. Inline images occupy screen rows at the cursor; in iTerm2 and compatible implementations they can be scaled to cell/pixel/percent dimensions. File transfer without `inline=1` has no in-stream visual representation. WezTerm supports `doNotMoveCursor=1` as an extension, useful when image output must not advance the cursor. Badges are iTerm2 chrome, not text cells, and have no portable rendering equivalent. Marks are scrollback navigation affordances; iTerm2 uses a small gutter triangle, while OSC 133 implementations may draw their own prompt/command marks. An application should not expect another terminal to show the same badge, annotation, fireworks, or mark appearance.

## Terminal support snapshot

This is feature-level support, not a claim that each app implements every command above. The protocol is proprietary and support changes by release; the inventory records what current public documentation/source makes support defensible.

| Terminal                    | OSC 1337 status                                                           | Developer notes                                                                                                                                                                                                                                                                                       |
|-----------------------------|---------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| iTerm2                      | Native, broad implementation                                              | Reference implementation. Use BEL or ST. For tmux integration and large payloads use multipart chunks; current iTerm2 and tmux cap chunks at 1 MiB, while older tmux versions may cap the whole sequence at 256 bytes. Retina sizing behavior changed in 3.2.                                         |
| WezTerm                     | Partial: `File=` images and `SetUserVar`                                  | Supports the iTerm image protocol and documents `doNotMoveCursor=1`. Image support does not imply support for badge, marks, or profile commands. Its escape-sequence page cautions that it is a living document.                                                                                      |
| Ghostty                     | Partial/compatibility, not namespace-wide                                 | Ghostty has implemented select iTerm2-compatible commands (notably copy/current-directory integrations in some releases) while its primary shell integration is OSC 133 and its image protocol support is separate. Check the version-specific OSC source/docs before depending on a 1337 subcommand. |
| cmux                        | Inherited/partial via embedded Ghostty terminal                           | cmux embeds GhosttyKit, so underlying Ghostty parser/rendering behavior is the relevant baseline; cmux adds its own shell integration and UI. Do not infer full iTerm2 support from the app name or its compatibility layer. Confirm a target cmux build for the exact command.                       |
| Konsole                     | Partial: `File=` inline image subset                                      | Public compatibility references report iTerm image-protocol support, not the wider iTerm2 namespace. Use a fallback for all non-image commands.                                                                                                                                                       |
| kitty                       | No OSC 1337 implementation established                                    | kitty has its own graphics protocol, shell integration (OSC 133), and user-variable-like features mediated through its own mechanisms. Use kitty graphics when targeting kitty rather than assuming `File=` compatibility.                                                                            |
| Apple Terminal              | No documented support                                                     | Use text/Unicode or another fallback; OSC 7 and other common sequences should be treated independently.                                                                                                                                                                                               |
| Alacritty                   | No documented support                                                     | Does not implement iTerm2's proprietary image protocol; its own documented terminal features do not include this family.                                                                                                                                                                              |
| Contour                     | No documented support                                                     | Supports semantic shell integration via OSC 133 and graphics alternatives; that is not OSC 1337.                                                                                                                                                                                                      |
| Foot                        | No documented support                                                     | Implements FinalTerm/OSC 133 semantic zones; use a separate image protocol/fallback.                                                                                                                                                                                                                  |
| GNOME Terminal (VTE)        | No documented support                                                     | VTE-based terminals implement various common OSCs but no iTerm2 1337 commands were found. Shell markers are a separate capability.                                                                                                                                                                    |
| Visual Studio Code terminal | No documented support for 1337 family                                     | Its shell integration uses OSC 633; do not confuse that with iTerm2 OSC 1337.                                                                                                                                                                                                                         |
| mintty                      | Reported by some capability detectors as accepting iTerm2 image sequences | Treat as a compatibility target only after version-specific testing; documentation is less definitive than for iTerm2/WezTerm.                                                                                                                                                                        |
| Windows Terminal            | No documented support for 1337 family                                     | Supports OSC 133 shell integration; this is not evidence of OSC 1337 support.                                                                                                                                                                                                                         |

For shell integration specifically, prefer OSC 133's prompt/input/command/output boundaries and OSC 7 current-directory reporting when those semantics are what the application needs. iTerm2 itself supports both its proprietary shell metadata and the separate OSC 133 family. This distinction matters in capability tables: “supports shell integration” does not mean “supports OSC 1337.”
