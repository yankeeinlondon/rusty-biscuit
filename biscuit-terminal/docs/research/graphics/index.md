# Terminal Graphics

There are three graphics standards for terminal apps:

1. **Kitty** graphics
2. **iTerm2** graphics
3. **Sixel** graphics

Biscuit Terminal's primary rendering tool is **Kitty Graphics** but it can detect all three and to have a fully rounded view of the Terminal world's graphics options you must know about all three to a degree.
