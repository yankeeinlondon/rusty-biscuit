        - class: literal text is serialized to Markdown without escaping its backslashes, so the syntax a neighboring node emits next (a soft break's newline, a hard break's backslash, a closing `**`, a cell's `<br>`, a link title's closing quote) turns the backslash into an escape and changes the text or break meaning

        - escaping-scope decision: only backslashes a CommonMark reader would consume are doubled — one before ASCII punctuation or a line ending, and one at the end of a `Text` value (its follower comes from a sibling node it cannot see). `C:\dir` stays byte-identical. Other punctuation (`*`, `_`, `[`, `#`) is deliberately not escaped: it would rewrite nearly every darkmatter/Markdown snapshot, and the reviewed defect is backslash consumption. Escaping backslashes also improves darkmatter's round trip (a source `\\` parses to `Text("\")` and is now written back as `\\`).
