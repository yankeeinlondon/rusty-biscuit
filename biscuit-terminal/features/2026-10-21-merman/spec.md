# Merman Rendering

Currently biscuit-terminal and biscuit-visualized use the [markdown-rs-renderer](https://github.com/1jehuang/mermaid-rs-renderer.git) crate to render Mermaid diagrams to SVG or raster images but it appears that [Merman](https://github.com/Latias94/merman) is likely the better option:

- it is much more up-to-date
- it has the Zed editor's developers backing Merman
