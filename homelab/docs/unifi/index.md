# Unifi

## Company and Brand

**Ubiquiti** is a leading networking company that targets the prosumer marketplace while trending to larger and larger business needs. It's flagship brand is **Unifi**.

::summarize company.md length="1 paragraph"

If you want more details on **Ubiquiti** as a company or the **Unifi** brand, read: [Unifi Brand Details](./brand.md).

## Service Offerings

### Network

The **Network** service offering is the most mature part of the **Unifi** suite and what most people immediately think of when they hear the name **Unifi**. To find out more about the offering as well as the mobile app that supports the Network offering read [Network Service and Application](./network.md).

The network service is also fully supported on the [Unifi Web Application](./web-app.md).

If you want the specs for a particular product in the network service, you will find it in one of the following links:

- [Unifi Routers and Gateways](./routers.md)
- [Unifi Switches](./switches.md)
- [Unifi Access Points](./ap.md)

### Protect

The **Protect** service line helps users to capture, observe, and manage security feeds. For details on this service offering as well as the **Protect** mobile application read [Protect Service and Mobile Application](./protect.md).

Like the network service, the **Protect** service offering is fully supported by the [Unifi Web Application](./web-app.md) in addition to the mobile app.

While the **Protect** service offering is more than just security cameras, if what you're looking for is the specs of a particular security camera you'll find them all here: [Unifi Security Cameras](./security-camera.md).

### Access

The **Access** service line helps users interact with physical security devices like door locks, gates, and more. For more details on this service offering as well as the mobile app supporting it you should read: [Unifi Access Service and Mobile Application](./access.md).

## Products

### Routers

The ever popular "UDM (Unified Dream Machine)" and "UDM Pro" lines continue to be big hits in the WAN/Routers space for Unifi but their product offering continues to grow.

To find out more details on all of the routers Unifi provides, read: [Unifi Routers](./routers.md)

### Switches

**Unifi** offers a huge lineup of managed switches which are all exposed in the [Network Application](./network-app.md). For details on the switches that **Unifi** offers read: [Unifi Switches](./switches.md).

### Security Cameras

A big part of the **Protect** service line is providing security camera footage along with the associated events and metadata in a meaningful way. To find out more about security cameras which **Unifi** provides, read: [Security Cameras](./security-cameras.md).

> **Note:** security cameras include specialized equipment like doorbell cameras, etc.

## Applications

Part of the **Unifi** experience for users is the high quality, visually appealing software that works with the **Unifi** hardware. 

- you can access these "apps" on the web via: https://unifi.ui.com/consoles 
    - the web application has functionality for all of the service offerings
    - find out more at [Unifi Web Application](./web-app.md) 
- In addition mobile platforms have individual apps for each service line (Network, Protect, Access, etc.)
- Finally, mobile platforms also have the powerful **WIFIman** app which can help users diagnose and optimize their networks. For more on this power tool read [WIFIman Application](./wifiman.md)

For more details on the apps, their functionality, version history, and more ... read: [./unifi-apps.md].

## APIs

Unifi has recently been introducing and improving a set of API's that helps developers integrate with their Unifi hardware. To find out more about these APIs read: [Unifi APIs](./api.md).
