# Noto Emoji

The monochrome [Noto Emoji](https://fonts.google.com/noto/specimen/Noto+Emoji)
font, compiled into `biscuit-visualized` (feature `image`) on Linux only, as
the last fallback for emoji.

- Source: [google/fonts](https://github.com/google/fonts) `ofl/notoemoji/`
  at commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5` (2026-03-12)
- Download: <https://raw.githubusercontent.com/google/fonts/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji/NotoEmoji%5Bwght%5D.ttf>
- Upstream file name `NotoEmoji[wght].ttf`, renamed here to
  `NotoEmoji-Variable.ttf` so the name needs no shell quoting.
- This is a **variable** font (axis `wght` 300–700). No static Regular face is
  published upstream; renderers use the default instance, Regular 400.
