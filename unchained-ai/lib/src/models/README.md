This directory provides the core model type definitions: `ModelCapability` for abstract capability-based model selection, `ModelMetadata` and `Modality` for runtime model metadata, `metadata.rs` for richer provider-specific model shapes, and `identity.rs` for the wire-id identity grammar (`ModelIdentity::parse`, `latest_in_family`) that decomposes ids into source/vendor/family/version/variants and powers family-latest queries and cross-source model grouping.
