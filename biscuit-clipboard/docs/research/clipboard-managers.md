# Clipboard Managers

## macOS

### Paste

| Field            | Value                                                                                 |
|------------------|---------------------------------------------------------------------------------------|
| **Executable**   | `Paste` (`.app` bundle)                                                               |
| **Product page** | <https://pasteapp.io>                                            |

| **Pricing**      | <https://pasteapp.io/pricing> (subscription or lifetime) |

#### APIs / SDKs

- **Siri Shortcuts** integration for automating clipboard workflows
- **iCloud sync** via CloudKit (data never leaves device/iCloud)
- **Shared Pinboards** for team collaboration
- **Paste Keyboard** (iOS custom keyboard extension)
- No public REST/network API; no CLI; no scripting interface

#### Features

- Infinite clipboard history
- iCloud sync across Mac, iPhone, and iPad
- Pinboards for organizing clips (shared pinboards for teams)
- Search across all devices
- Preview and edit clips in-place
- Paste multiple items (keep or strip formatting)
- Custom rules for excluding sensitive apps
- Plain-text paste mode
- Native macOS UI (menu bar app)
- Dark mode support

### Maccy

| Field            | Value                                                                                                          |
|------------------|----------------------------------------------------------------------------------------------------------------|
| **Executable**   | `Maccy` (`.app` bundle)                                                                                        |
| **Product page** | <https://maccy.app>                                                                         |
| **Source code**  | <https://github.com/p0deje/Maccy>                                             |
| **Docs**         | <https://github.com/p0deje/Maccy/blob/master/README.md> |
| **License**      | MIT (open source)                                                                                              |

#### APIs / SDKs

- **`defaults` CLI** for programmatic configuration (e.g., `defaults write org.p0deje.Maccy ignoreEvents true`)
- **Pasteboard type filtering** via `org.nspasteboard.*` conventions (TransientType, ConcealedType, AutoGeneratedType)
- No REST/network API; no scripting language; no CLI for clipboard manipulation
- Configurable via standard macOS `defaults` domains

#### Features

- Lightweight, keyboard-first design
- Full-text search through clipboard history
- Pin items to persist at top of list
- Paste directly (auto-paste into active app)
- Paste without formatting
- Ignore copies from password managers and sensitive apps
- Ignore Universal Clipboard items
- Configurable clipboard check interval (default 500ms)
- Native macOS UI (Swift, AppKit)
- Menu bar app (no Dock icon)
- Open source and free
- Available via Homebrew (`brew install maccy`) and Mac App Store
- Requires macOS Sonoma 14+

### Sniff (System Detection Tool)

> **Note:** Sniff is not a clipboard manager. It is a cross-platform system detection tool from the Rusty Biscuit monorepo. It is included here because its program detection module can inventory installed clipboard managers across macOS, Linux, and Windows.

| Field           | Value                                  |
|-----------------|----------------------------------------|
| **Executable**  | `sniff`                                |
| **Source code** | `sniff/` in the Rusty Biscuit monorepo |
| **Library**     | `sniff/lib` (Rust crate)               |
| **CLI**         | `sniff/cli` (binary crate)             |

#### APIs / SDKs

- **Rust library** (`sniff/lib`) with three API tiers:

  - `detect()` — convenience, detect everything
  - `detect_with_plan(DetectionPlan)` — fine-grained control
  - Module-level functions for expert composition

- **CLI** with subcommand filtering (`sniff programs`, `sniff hardware`, etc.)
- **JSON output** (`--json` flag) for machine-readable results
- **Program detection module** — detects installed programs across 8 categories including utilities (clipboard managers would fall here)
- No REST/network API (runs locally; optional network for remote git inspection and version checks)

#### Features

- OS detection (distro, kernel, architecture, package managers, locale, timezone)
- Hardware detection (CPU with SIMD, GPU with Metal, memory, storage, audio)
- Network detection (interfaces, IPv4/IPv6, WAN IP)
- Filesystem analysis (git repos, monorepos, languages, file types, blast radius, justfiles)
- **Program inventory** across 8 categories with install support
- System services detection (10+ init systems)
- Remote repository inspection (GitHub, GitLab, Gitea, Bitbucket)
- Scoped enrichment (`--refresh-remotes`, `--latest-versions`)
- Cross-platform (macOS, Linux, Windows)

## Windows

### Ditto

| Field            | Value                                                                              |
|------------------|------------------------------------------------------------------------------------|
| **Executable**   | `Ditto.exe`                                                                        |
| **Product page** | <https://ditto-cp.sourceforge.io>                 |
| **Source code**  | <https://github.com/sabrogden/Ditto>           |
| **Wiki / Docs**  | <https://github.com/sabrogden/Ditto/wiki> |
| **License**      | GPL-3.0 (open source)                                                              |

#### APIs / SDKs

- **Win32 Clipboard API** consumer — monitors `WM_CLIPBOARDUPDATE` / clipboard chain messages
- **SQLite database** backend for storing clipboard history (local DB file, queryable)
- **Named pipes / DDE** for some inter-process communication
- **Addins API** — extensible via `DittoUtil` addin architecture (C++ plugin model)
- **No REST/network API**; no scripting language
- Configurable via GUI preferences (stored in registry / INI)
- Code-signed builds via SignPath.io

#### Features

- Unlimited clipboard history (text, images, HTML, custom formats)
- Search through history
- Copy any type of information the Windows clipboard supports
- System-wide hotkey (default \`Ctrl+\``)
- System tray icon with quick access
- Groups for organizing clips
- Quick-paste keyboard shortcuts (numbered entries)
- Portable mode available (no installer needed)
- Sync via shared SQLite DB on network drives (experimental)
- Local-first (no login, no cloud, no telemetry)
- Available via Chocolatey (`choco install ditto`), Scoop, Winget, and Microsoft Store
- Unicode support
- Thumbnail preview for images

## Linux

### CopyQ

| Field             | Value                                                                                                                  |
|-------------------|------------------------------------------------------------------------------------------------------------------------|
| **Executable**    | `copyq`                                                                                                                |
| **Product page**  | <https://hluk.github.io/CopyQ/>                                                         |
| **Source code**   | <https://github.com/hluk/CopyQ>                                                         |
| **Docs**          | <https://copyq.readthedocs.io>                                                           |
| **Scripting API** | <https://copyq.readthedocs.io/en/latest/scripting-api.html> |
| **License**       | GPL-3.0 (open source)                                                                                                  |

#### APIs / SDKs

- **Full scripting API** (JavaScript/ECMAScript) for automation:

  - Clipboard read/write: `clipboard()`, `copy()`, `paste()`
  - Item management: `add()`, `insert()`, `read()`, `write()`, `remove()`, `getItem()`, `setItem()`
  - Tab management: `tab()`, `removeTab()`, `renameTab()`
  - Configuration: `config()`, `settings()`
  - Network: `networkGet()`, `networkPost()`, `networkGetAsync()`, `networkPostAsync()`
  - Dialogs: `dialog()`, `popup()`, `notification()`, `menuItems()`
  - Process execution: `execute()`
  - Clipboard callbacks: `onClipboardChanged()`, `onOwnClipboardChanged()`, `onHiddenClipboardChanged()`
  - Screenshots: `screenshot()`, `screenshotSelect()`
  - Audio playback: `playSound()`

- **CLI interface** — full scripting from command line:

  - `copyq add 'text'` — add to history
  - `copyq clipboard` — read current clipboard
  - `copyq copy "Some Text"` — set clipboard
  - `copyq read 0 1 2` — read items by index
  - `copyq eval '<script>'` — evaluate script

- **Plugin system** with commands repository: <https://github.com/hluk/copyq-commands>
- Cross-platform (Linux, Windows, macOS)

#### Features

- Store text, HTML, images, and custom formats
- Organized tabs for clipboard items
- Sort, create, edit, remove, drag-and-drop items
- Add notes or tags to items
- System-wide customizable shortcuts
- Paste items with shortcut, tray, or main window
- Fully customizable appearance (themes)
- Advanced command-line interface
- Vim-like editor and shortcuts
- Ignore clipboard from specific windows or containing specific text
- Tree view for nested items
- Automatic and manual commands (triggers on clipboard change)
- Built-in encryption support
- Audio playback support
- Available via apt, dnf, pacman, brew, scoop, chocolatey, flatpak

### GPaste

| Field           | Value                                                                  |
|-----------------|------------------------------------------------------------------------|
| **Executable**  | `gpaste-client` (CLI), `gpaste-daemon` (daemon), `gpaste-ui` (GUI)     |
| **Source code** | <https://github.com/Keruspe/GPaste> |
| **Docs**        | README on GitHub; `man gpaste-client`                                  |
| **License**     | BSD-2-Clause (open source)                                             |

#### APIs / SDKs

- **`libgpaste`** — C library for development:

  - Manage preferences programmatically
  - Interact with the GPaste daemon
  - Core objects for clipboard management

- **`gpaste-client` CLI** with subcommands:

  - `gpaste-client ui` — launch graphical tool
  - `gpaste-client daemon-version` — check running daemon
  - `gpaste-client dr` / `daemon-reexec` — restart daemon after upgrades

- **GNOME Shell extension** — native integration with GNOME desktop
- **Keybindings** for: show history, pop item, sync primary/clipboard, mark as password, upload to pastebin (via wgetpaste)
- D-Bus interface for daemon communication
- Meson build system

#### Features

- GNOME Shell integration (native extension)
- Clipboard and primary selection management
- Sync between primary selection and clipboard (bidirectional)
- Password marking (hide sensitive items)
- Pastebin upload (via wgetpaste)
- History browsing and search
- Daemon-based architecture (runs as background service)
- Configurable keybindings
- Built with GTK/libadwaita for modern GNOME look
- Available via `dnf` on Fedora (`sudo dnf install gpaste-ui gpaste`)
- Supports GNOME 45–50
